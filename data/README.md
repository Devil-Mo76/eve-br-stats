# 数据目录说明

本目录保存程序运行时的全部数据。**通用版首次运行时，除 `ship_id.txt` 外均为空**，
需要你自己通过网页「管理」菜单或直接编辑文件来填写。

| 文件 / 目录 | 作用 | 格式 |
| --- | --- | --- |
| `corp_id.txt` | **要统计的军团**（战斗统计只收录这里的军团成员） | 每行 `军团ID_军团名称` |
| `char_id.txt` | 角色 ID 与名称映射 | 每行 `角色ID_角色名称` |
| `ship_id.txt` | EVE 舰船 ID 与名称映射（公共数据，已预置） | 每行 `舰船ID_舰船名称` |
| `br_links.txt` | 上次提交的 BR 链接，用于页面回显 | 每行一个链接 |
| `attendance.json` | 出勤统计记录（首次提交后自动生成） | JSON 数组 |
| `reports/` | 生成的 Excel 报表 | `.xlsx` 文件 |
| `system.log` | 关键操作与错误日志（自动生成） | 文本 |
| `detailed.log` | 程序运行详细日志（自动生成） | 文本 |

## 格式约定

- 编码统一为 **UTF-8**，每行一条记录。
- 分隔符是**第一个下划线** `_`，因此名称里允许再出现下划线，但 ID 必须写在最前面。
- 空行、以 `#` 开头的注释行会被自动忽略。

示例 `corp_id.txt`：

```
# 军团ID_军团名称（# 开头是注释，可以保留）
98769610_Example Corporation
12345678_Another Corporation
```

## 注意

- 数据目录默认位于程序同级目录，也可通过环境变量 `BR_DATA_DIR` 指定到别处。
- 打包成 EXE 后，数据写在 **EXE 所在目录** 的 `data/` 下，方便备份和迁移。
