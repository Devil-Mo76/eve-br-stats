系统功能

本系统用于分析 EVE Online 中的战斗报告（BR），统计指定军团成员的作战数据与出勤情况，并导出为 Excel 报表。

主要功能包括：

  • 解析多个 BR 链接，统计成员出击次数、击杀数、总伤害与使用舰船
  • 按舰队活动记录成员出勤，生成出勤次数排行并导出 Excel
  • 生成带柱状图（伤害 / 击杀数 Top10）的 Excel 报表

[战斗统计分析]使用步骤

  1. 先到「管理 → 军团管理」添加你要统计的军团 ID 与名称（首次使用必须配置，否则会提示未配置军团）
  2. 在首页填写「选择报告日期」和「自定义报告名称」
  3. 粘贴 BR 链接（每行一个，格式形如 https://br.evetools.org/br/xxxxxxxx）
  4. 点击「生成报告」，完成后点击「下载最新报告」，文件默认下载到浏览器下载目录

[出勤统计分析]使用步骤

  1. 填写「报告日期」并选择「报告类型」
  2. 可选填舰队说明
  3. 在角色列表中粘贴本次出队的成员名称，每行一个角色名
  4. 点击「添加舰队角色」，右侧会实时刷新出勤次数统计
  5. 需要存档时点击「导出Excel」下载报表

[管理]页面说明

  • 军团管理：维护要统计的军团 ID / 名称，数据保存在 data/corp_id.txt
  • 角色管理：手动补充或修正角色 ID / 名称映射，数据保存在 data/char_id.txt
  • 历史报告：查看、下载、删除已生成的历史报表
  • 系统日志：查看 data/system.log，用于排查报错

注意事项

  1. 尽量不要开启 VPN 进行 BR 统计分析，避免接口连接异常
  2. 出现报错请刷新页面重试，或更换网络后重试
  3. 不要在短时间内高频统计 BR，避免被数据源接口限流
  4. 出勤数据保存在 data/attendance.json，请勿手工损坏该文件

二次开发：需要你自己改的地方

本项目为通用版本，所有品牌信息与行为参数都集中在 config.py。 在源码中搜索 TODO(通用版) 或 【需修改】 即可定位全部需要调整的位置。 完整手册见仓库根目录 操作手册.md（中文）与 OPERATION_MANUAL_EN.md（English），第 6 / 11 章即为配置清单。

  • 系统名称 / 页脚文案 / LOGO / 背景图 → config.py
  • 监听地址与端口 / SECRET_KEY → config.py
  • 出勤「报告类型」下拉选项 → config.py 的 EVENT_TYPES
  • 数据源接口地址 / BR 链接格式 → config.py
  • 打包文件名与 EXE 图标 → build.py、version_info.txt
